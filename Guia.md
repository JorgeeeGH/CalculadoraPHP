# Guía de uso
## Esto es una guía de uso para saber como usar la calculadora creada.

1. Introducir el primer número.
2. Introducir el segundo número.
3. Seleccionar la operación que se desee realizar.
4. Pulsar en el botón **Realizar operación**.

**NOTA:** Sólo se puede realizar una sola operación al mismo tiempo.
